Flash DRAC OS from your browser

No PlatformIO, no toolchain — Chrome or Edge on desktop talks to the board's ROM bootloader directly over USB. Works on a genuinely blank board.

Install

Your browser doesn't support Web Serial. Open this page in Chrome or Edge on desktop instead.
Web Serial requires HTTPS. You're seeing this because the page isn't served securely — this shouldn't happen on the published GitHub Pages URL.

Requires a USB-C data cable (not charge-only) and Chrome or Edge on desktop.

First boot, step by step

  1. Plug the board into your computer with a USB-C data cable.
  2. Click Connect & Install above and pick the board's serial port.
  3. On a new board, choose Erase device and install when prompted.
  4. After it reboots, the board creates its own WiFi access point named Radar-GPX (password radar123) — connect to configure it. From here on, the board can be updated over WiFi too; you won't need this page or a cable again.
  5. To generate waypoint files to load onto the device, go to the GPX Generator.

Already flashed? Update over WiFi instead

Once DRAC OS is running, you don't need this page or a cable again — open the device's own web portal at /update and upload the -ota.bin release asset. This page's installer always does a full flash, meant for first-time setup or recovery.
